# Спринт 05. Files API и SeaweedFS

## Цель

Добавить загрузку изображений в S3-compatible хранилище SeaweedFS и вернуть URL, пригодный для отображения на публичном сайте.

После спринта административная панель сможет отправлять файл на backend, backend будет сохранять его в SeaweedFS и возвращать публичную ссылку.

## Контекст

Проекты имеют изображение или логотип. В базе хранится только `imageUrl`, а сами файлы лежат в SeaweedFS. Backend является единственной точкой загрузки файлов и должен валидировать входящие данные.

## Задачи

### Конфигурация хранилища

- Добавить настройки:
  - S3 endpoint;
  - access key;
  - secret key;
  - bucket name;
  - public base URL;
  - force path style, если требуется клиенту.
- Для локального Docker Compose использовать endpoint `http://seaweedfs:8333`.
- Для публичных URL в локальной разработке использовать `http://localhost:8333/portfolio`.

### S3 client

- Подключить S3-compatible клиент.
- Реализовать сервис файлового хранилища.
- Проверять существование bucket.
- Создавать bucket при необходимости, если это допустимо для local/dev.

### Upload endpoint

- Реализовать `POST /api/admin/files`.
- Защитить endpoint через JWT.
- Принимать `multipart/form-data`.
- Поддержать поля:
  - `file`;
  - `folder` необязательный.
- Для проектов использовать папку `projects`.

### Валидация файлов

- Разрешить MIME-типы:
  - `image/jpeg`
  - `image/png`
  - `image/webp`
  - `image/svg+xml`
- Ограничить размер файла до 5 MB.
- Возвращать `400 Bad Request`, если файл отсутствует, тип запрещен или размер превышен.

### Имена файлов

- Сформировать безопасное имя объекта.
- Избежать конфликтов имен:
  - UUID в имени;
  - timestamp;
  - slugified original name.
- Сохранить расширение файла.
- Не доверять оригинальному имени файла как готовому object key.

### Response

- Возвращать:
  - `fileName`
  - `contentType`
  - `size`
  - `url`

## Результат спринта

- Backend принимает изображения.
- Файлы сохраняются в SeaweedFS.
- Backend возвращает публичный URL.
- URL можно сохранить в поле `Project.imageUrl`.

## Definition of Done

- `POST /api/admin/files` требует авторизацию.
- Валидное изображение загружается и возвращает `201 Created`.
- Файл доступен по возвращенному URL в локальном окружении.
- Невалидный MIME-type возвращает `400 Bad Request`.
- Файл больше 5 MB возвращает `400 Bad Request`.
- Настройки хранилища вынесены в конфигурацию.

## Риски и решения

- В production bucket может быть закрыт. Тогда публичный URL должен вести через CDN или backend proxy. Для MVP можно использовать публичный base URL из конфигурации.
- SVG потенциально может содержать опасный контент. Если SVG разрешен, нужно учитывать это в security pass.
- SeaweedFS в Docker должен быть стабильно доступен и для backend-контейнера, и для браузера пользователя через разные адреса.

## Что не входит в спринт

- UI загрузки изображения.
- Удаление старых файлов при обновлении проекта.
- CDN.
- Оптимизация изображений.
