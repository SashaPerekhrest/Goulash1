# Спринт 08. Admin About

## Цель

Реализовать административную страницу редактирования HTML-контента "О себе" через TinyMCE.

После спринта администратор сможет открыть раздел "О себе", изменить контент, сохранить его и увидеть изменения на публичной странице.

## Контекст

Контент страницы "О себе" хранится в таблице `page_contents` с ключом `about`. Backend API для чтения и обновления уже должен быть готов к этому спринту.

## Задачи

### TinyMCE

- Подключить TinyMCE.
- Создать reusable компонент `TinyEditor`.
- Настроить базовую панель инструментов.
- Проверить работу с HTML:
  - headings;
  - paragraphs;
  - lists;
  - links;
  - basic formatting.

### Страница `/admin/about`

- Загружать текущий контент через `GET /api/admin/pages/about`.
- Показывать loading state.
- Показывать error state, если загрузка не удалась.
- Отображать TinyMCE с текущим HTML.
- Сохранять изменения через `PUT /api/admin/pages/about`.

### Form state

- Можно использовать React Hook Form или локальное состояние, если это проще.
- Блокировать кнопку сохранения во время запроса.
- Отслеживать измененность формы, если это не усложняет реализацию.

### UX состояния

- Отображать:
  - загрузку;
  - сохранение;
  - успешное сохранение;
  - ошибку сохранения.
- После успешного сохранения обновлять кеш TanStack Query.

### Проверка публичной стороны

- После сохранения проверить, что `GET /api/pages/about` возвращает новый HTML.
- Проверить, что публичная страница `/` отображает обновленный контент.

## Результат спринта

- Раздел "О себе" в админке работает.
- Контент редактируется через TinyMCE.
- Изменения сохраняются в backend и отражаются на публичном сайте.

## Definition of Done

- `/admin/about` доступен только авторизованному пользователю.
- Текущий HTML загружается из backend.
- HTML можно изменить и сохранить.
- При успешном сохранении пользователь видит подтверждение.
- При ошибке пользователь видит понятное сообщение.
- Публичная страница `/` показывает обновленный HTML.

## Риски и решения

- TinyMCE может требовать API key или специальную конфигурацию. Для MVP нужно выбрать вариант, который стабильно работает локально.
- HTML, созданный редактором, может содержать стили и атрибуты. Это должно быть согласовано с backend sanitizer/security strategy.
- Если editor component слишком связан с About-страницей, позже его будет сложнее использовать в форме проекта. Лучше сразу сделать его переиспользуемым.

## Что не входит в спринт

- Редактирование проектов.
- Загрузка изображений.
- Расширенная медиабиблиотека.
- Предпросмотр публичной страницы внутри админки.
